# Componentes de terceiros

Os componentes externos mantêm suas próprias licenças e atribuições. Os avisos
deste arquivo complementam, sem substituir, os textos de licença incluídos.

## Blockly

Os arquivos distribuídos em `micro_arca_app/assets/blockly/` incluem o Blockly,
utilizado para o editor de programação em blocos. A licença Apache 2.0 está em
[BLOCKLY_LICENSE.txt](micro_arca_app/assets/blockly/BLOCKLY_LICENSE.txt).
Os cabeçalhos de copyright e os avisos presentes nos arquivos foram preservados.

## Fira Code

As fontes em `micro_arca_app/assets/fonts/` pertencem ao projeto Fira Code e
mantêm a SIL Open Font License 1.1. O texto integral e o copyright estão em
[OFL.txt](micro_arca_app/assets/fonts/OFL.txt). A licença do código do MicroARCA
não substitui a licença dessas fontes.

Fonte: [Fira Code](https://github.com/tonsky/FiraCode).

## Dependências e firmware

As dependências Flutter/Dart estão identificadas em `pubspec.yaml` e
`pubspec.lock`; cada uma conserva a licença de seu projeto. O MicroPython é
um firmware externo: este repositório contém os módulos Python do MicroARCA
instalados sobre ele, e não uma transferência de autoria do firmware.

As bibliotecas distribuídas pelo catálogo têm seus próprios avisos de licença
e proveniência no [repositório do catálogo](https://github.com/gabriel26077/SistemaMicroARCA).
